# gong-guide-data

환경·화학·화공 직렬 공공기관 채용공고 스냅샷. `collect_jobs.py`가 잡알리오(중앙 공공기관)와 클린아이 잡플러스(지방공공기관)에서 접수 중인 공고, 기관별 과거 경쟁률(알리오 공시), 신입 초임(알리오 경영공시)을 받아 `data/jobs.json`에 쓴다. 전부 공개 공시 자료이고 개인 정보는 없다.

- 실행: `python collect_jobs.py` (표준 라이브러리만, 인증키 불필요)
- 결과: `data/jobs.json` — 안내서 페이지가 열릴 때 이 파일을 받아 그린다.
